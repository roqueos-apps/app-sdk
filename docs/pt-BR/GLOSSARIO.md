# Glossário

_[English](../GLOSSARY.md) | Português_

> **Para quem:** quem lê o código ou estes documentos e encontra uma palavra que quer dizer uma coisa específica aqui.
> **O que tem aqui:** cada termo como aparece no código, o que é e onde mora.
> **Onde ir para o resto:** formas e formatos estão em [REFERENCIA.md](REFERENCIA.md); os motivos, em [ARQUITETURA.md](ARQUITETURA.md).

| Termo                        | O que é                                                                                                                         | Onde mora                                                                                          |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `sistema` (host)             | o objeto que o app recebe no `mount`, com `versaoDoContrato` e as capacidades                                                   | [`src/contrato.js`](../../src/contrato.js)                                                         |
| capacidade                   | uma coisa que o sistema oferece ao app, com forma e motivo escrito                                                              | `CAPACIDADES` em [`src/contrato.js`](../../src/contrato.js)                                        |
| obrigatória / opcional       | as seis que todo sistema tem, e as que o app lista em `capacidades` para exigir                                                 | `OBRIGATORIAS`, `OPCIONAIS` em [`src/contrato.js`](../../src/contrato.js)                          |
| contrato, `versaoDoContrato` | o conjunto de capacidades e as formas delas; versão 1 hoje. Sistema em outra versão recusa o app                                | `VERSAO_DO_CONTRATO` em [`src/contrato.js`](../../src/contrato.js)                                 |
| `definirApp`                 | a função que transforma `{ id, capacidades, montar }` num app com `mount`                                                       | [`src/index.js`](../../src/index.js)                                                               |
| `mount` / `montar`           | `mount` é o que a janela chama; `montar` é a função do próprio app, chamada só depois de o sistema passar na conferência        | [`src/index.js`](../../src/index.js)                                                               |
| montagem                     | o que o `montar` devolve: `{ ativar, desmontar }`                                                                               | [`src/index.js`](../../src/index.js)                                                               |
| `ativar`                     | a janela ganhou ou perdeu o foco                                                                                                | [`src/index.js`](../../src/index.js)                                                               |
| camada                       | `primeira-parte` (nosso, mesma origem, dez idiomas) ou `comunidade` (qualquer pessoa, iframe em outra origem; ainda não existe) | `CAMADAS` em [`src/manifesto.js`](../../src/manifesto.js)                                          |
| manifesto, `app.json`        | o app dizendo quem ele é: id, nomes, janela, capacidades                                                                        | [`src/manifesto.js`](../../src/manifesto.js)                                                       |
| `app check`                  | o CLI que confere um repo de app inteiro contra o contrato                                                                      | [`bin/app.mjs`](../../bin/app.mjs), [`src/verificacao.js`](../../src/verificacao.js)               |
| sistema do RoqueOS           | a implementação por cima das stores do RoqueOS, no `roqueos-front`, fechado                                                     | fora deste repositório                                                                             |
| sistema de desenvolvimento   | a implementação sobre o navegador puro, para o `yarn dev`                                                                       | [`src/host/desenvolvimento.js`](../../src/host/desenvolvimento.js)                                 |
| janela falsa                 | a janela parecida com a do RoqueOS que o `montarNaJanelaFalsa` desenha em volta do app                                          | [`src/host/desenvolvimento.js`](../../src/host/desenvolvimento.js)                                 |
| sistema falso                | o contrato inteiro em memória, para teste                                                                                       | [`src/host/falso.js`](../../src/host/falso.js)                                                     |
| registro                     | o que o sistema falso viu o app fazer: avisos, eventos, arquivos, painéis, pastas abertas, pedidos de tela cheia                | [`src/host/falso.js`](../../src/host/falso.js)                                                     |
| coleção, `colecoes`          | documentos com nome na conta da pessoa; o sistema tem o mapa de onde cada um mora                                               | [`src/colecoes.js`](../../src/colecoes.js)                                                         |
| carimbo                      | `criadoEm` e `atualizadoEm`, em milissegundos, que só o sistema escreve                                                         | `CARIMBOS` em [`src/colecoes.js`](../../src/colecoes.js)                                           |
| pasta                        | um identificador dos Arquivos da pessoa (`Documentos`, `Imagens`, `Videos`), e não um caminho                                   | `PASTAS_DE_ARQUIVOS` em [`src/arquivos.js`](../../src/arquivos.js)                                 |
| ref                          | um ponteiro opaco para um arquivo, que vale para um app numa sessão                                                             | [`src/arquivos.js`](../../src/arquivos.js)                                                         |
| cofre de refs                | o que torna a ref opaca: emite e resolve refs para um app e uma sessão                                                          | `criarCofreDeRefs` em [`src/arquivos.js`](../../src/arquivos.js)                                   |
| anexo                        | bytes do próprio app na conta, por um id `anx_` durável que nunca vira URL                                                      | [`src/anexos.js`](../../src/anexos.js)                                                             |
| abertura                     | o que quem abriu a janela mandou, e os pedidos novos com ela aberta                                                             | [`src/abertura.js`](../../src/abertura.js)                                                         |
| "abrir com"                  | o Finder entregando um arquivo ao app que declara o tipo em `abre`                                                              | [`src/arquivos.js`](../../src/arquivos.js), [`src/abertura.js`](../../src/abertura.js)             |
| `ErroDoSistema`, `codigo`    | o erro com que uma capacidade opcional rejeita; o app decide pelo código                                                        | [`src/erros.js`](../../src/erros.js)                                                               |
| variáveis do sistema         | as variáveis CSS `--ros-*` do tema que um app pode ler; contrato com o tema do RoqueOS                                          | [`src/variaveis.js`](../../src/variaveis.js)                                                       |
| modo leve                    | o aparelho pede sem efeito de sensor, sem animação contínua, sem sombra pesada                                                  | `desempenho` em [`src/contrato.js`](../../src/contrato.js)                                         |
| modo E2E                     | `window.__ROS_E2E__` semeado por um harness de teste; o app instala o gancho de QA                                              | [`src/e2e.js`](../../src/e2e.js)                                                                   |
| tag na main                  | a regra de que a tag de release mora num commit que já está na `main`                                                           | [`bin/tag-na-main.mjs`](../../bin/tag-na-main.mjs)                                                 |
| DCO, `Signed-off-by`         | a linha do Developer Certificate of Origin que todo commit leva                                                                 | [CONTRIBUTING.md](CONTRIBUTING.md), [`.github/workflows/dco.yml`](../../.github/workflows/dco.yml) |
| `ASSETS.md`                  | o livro de um repo de app: caminho, licença e origem de cada arquivo de `public/`                                               | `conferirAssets` em [`src/verificacao.js`](../../src/verificacao.js)                               |

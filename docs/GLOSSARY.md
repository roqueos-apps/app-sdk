# Glossary

_English | [Português](pt-BR/GLOSSARIO.md)_

> **Who it is for:** whoever reads the code or these documents and meets a word that means something specific here.
> **What is here:** each term as it appears in the code (Portuguese), what it is, and where it lives.
> **Where to go for the rest:** shapes and formats are in [REFERENCE.md](REFERENCE.md); the reasons, in [ARCHITECTURE.md](ARCHITECTURE.md).

| Term                                          | What it is                                                                                                          | Where it lives                                                                                     |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `sistema` (system, host)                      | the object the app receives in `mount`, with `versaoDoContrato` and the capabilities                                | [`src/contrato.js`](../src/contrato.js)                                                            |
| capacidade (capability)                       | one thing the system offers the app, with a shape and a written reason                                              | `CAPACIDADES` in [`src/contrato.js`](../src/contrato.js)                                           |
| obrigatória / opcional (mandatory / optional) | the six every system has, and the ones an app lists in `capacidades` to require                                     | `OBRIGATORIAS`, `OPCIONAIS` in [`src/contrato.js`](../src/contrato.js)                             |
| contrato, `versaoDoContrato`                  | the set of capabilities and their shapes; version 1 today. A system on another version refuses the app              | `VERSAO_DO_CONTRATO` in [`src/contrato.js`](../src/contrato.js)                                    |
| `definirApp`                                  | the function that turns `{ id, capacidades, montar }` into an app with `mount`                                      | [`src/index.js`](../src/index.js)                                                                  |
| `mount` / `montar`                            | `mount` is what the window calls; `montar` is the app's own function, called only after the system passed the check | [`src/index.js`](../src/index.js)                                                                  |
| montagem                                      | what `montar` returns: `{ ativar, desmontar }`                                                                      | [`src/index.js`](../src/index.js)                                                                  |
| `ativar`                                      | the window gained or lost focus                                                                                     | [`src/index.js`](../src/index.js)                                                                  |
| camada (layer)                                | `primeira-parte` (ours, same origin, ten languages) or `comunidade` (anyone, cross-origin iframe; not built yet)    | `CAMADAS` in [`src/manifesto.js`](../src/manifesto.js)                                             |
| manifesto, `app.json`                         | the app saying who it is: id, names, window, capabilities                                                           | [`src/manifesto.js`](../src/manifesto.js)                                                          |
| `app check`                                   | the CLI that checks a whole app repository against the contract                                                     | [`bin/app.mjs`](../bin/app.mjs), [`src/verificacao.js`](../src/verificacao.js)                     |
| sistema do RoqueOS                            | the implementation on top of RoqueOS's stores, in the closed `roqueos-front`                                        | not in this repository                                                                             |
| sistema de desenvolvimento                    | the implementation over the plain browser, for `yarn dev`                                                           | [`src/host/desenvolvimento.js`](../src/host/desenvolvimento.js)                                    |
| janela falsa (fake window)                    | the RoqueOS-like window `montarNaJanelaFalsa` draws around the app                                                  | [`src/host/desenvolvimento.js`](../src/host/desenvolvimento.js)                                    |
| sistema falso (fake system)                   | the whole contract in memory, for tests                                                                             | [`src/host/falso.js`](../src/host/falso.js)                                                        |
| registro                                      | what the fake system saw the app do: notices, events, files, panels, folders opened, full-screen requests           | [`src/host/falso.js`](../src/host/falso.js)                                                        |
| coleção, `colecoes`                           | named documents in the person's account; the system has the map of where each lives                                 | [`src/colecoes.js`](../src/colecoes.js)                                                            |
| carimbo (stamp)                               | `criadoEm` and `atualizadoEm`, in milliseconds, written only by the system                                          | `CARIMBOS` in [`src/colecoes.js`](../src/colecoes.js)                                              |
| pasta (folder)                                | an identifier for the person's Files (`Documentos`, `Imagens`, `Videos`), not a path                                | `PASTAS_DE_ARQUIVOS` in [`src/arquivos.js`](../src/arquivos.js)                                    |
| ref                                           | an opaque pointer to a file, valid for one app in one session                                                       | [`src/arquivos.js`](../src/arquivos.js)                                                            |
| cofre de refs (ref vault)                     | what makes the ref opaque: it issues and resolves refs for one app and one session                                  | `criarCofreDeRefs` in [`src/arquivos.js`](../src/arquivos.js)                                      |
| anexo (attachment)                            | the app's own bytes in the account, under a durable `anx_` id that never becomes a URL                              | [`src/anexos.js`](../src/anexos.js)                                                                |
| abertura (opening)                            | what whoever opened the window sent, and new requests while it is open                                              | [`src/abertura.js`](../src/abertura.js)                                                            |
| "abrir com" (open with)                       | the Finder handing one file to an app that declares the type in `abre`                                              | [`src/arquivos.js`](../src/arquivos.js), [`src/abertura.js`](../src/abertura.js)                   |
| `ErroDoSistema`, `codigo`                     | the error an optional capability rejects with; the app decides by the code                                          | [`src/erros.js`](../src/erros.js)                                                                  |
| variáveis do sistema                          | the `--ros-*` CSS variables of the theme an app may read; contract with RoqueOS's theme                             | [`src/variaveis.js`](../src/variaveis.js)                                                          |
| modo leve (low-end mode)                      | the device asks for no sensor effects, no continuous animation, no heavy shadow                                     | `desempenho` in [`src/contrato.js`](../src/contrato.js)                                            |
| modo E2E                                      | `window.__ROS_E2E__` seeded by a test harness; the app installs its QA hook                                         | [`src/e2e.js`](../src/e2e.js)                                                                      |
| tag na main                                   | the rule that a release tag lives on a commit already in `main`                                                     | [`bin/tag-na-main.mjs`](../bin/tag-na-main.mjs)                                                    |
| DCO, `Signed-off-by`                          | the Developer Certificate of Origin line every commit carries                                                       | [CONTRIBUTING.md](../CONTRIBUTING.md), [`.github/workflows/dco.yml`](../.github/workflows/dco.yml) |
| `ASSETS.md`                                   | the ledger of an app repository: path, licence and origin of every file in `public/`                                | `conferirAssets` in [`src/verificacao.js`](../src/verificacao.js)                                  |
